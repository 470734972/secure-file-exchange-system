# 受控文件交换平台 Demo

本 Demo 用一个 Node.js 服务模拟“同一套系统、办公网和研发网分别通过不同入口访问”的文件流转流程。

## 本地运行

需要 Node.js 18 或更高版本。

```powershell
npm start
```

用浏览器分别访问：

- 办公网入口：`http://127.0.0.1:8080`
- 研发网入口：`http://127.0.0.1:8081`

在任一入口提交 `.txt`、`.pdf`、`.csv`、`.png` 或 `.jpg` 文件。源区执行“模拟批准并投递”后，切换到对侧入口即可下载。文件、任务数据、审计日志保存在运行目录下的 `data/`，已被 Git 忽略。

## Rocky Linux 双 IP 演示部署

以下为**同机双 IP 入口的流程演示**，不构成物理隔离：

```bash
OFFICE_IP=10.10.10.10 RD_IP=10.20.20.10 PORT=8080 node server.js
```

应用依据 TCP 连接实际到达的本机 IP（`socket.localAddress`）决定区域；未知入口 IP 返回 403。它不信任浏览器的 `Host`、`X-Forwarded-For`、URL 参数或表单字段。

生产建议以前置 Nginx 分别监听两条 IP 的 HTTPS 入口、应用仅监听回环地址，并在网络层使用 VLAN/ACL/网闸进一步隔离。

## Demo 边界（禁止用于生产）

- 基础检测与 DLP 仅是演示规则，不包含 AV、沙箱、CDR、真实 DLP、SSO、MFA、KMS、HA 或灾备。
- 两个 IP 同在一台主机只模拟入口分区，不能等同网闸、物理隔离或涉密跨网交换。
- 不要上传源代码、个人信息、涉密资料或真实不可信文件。
- 生产应使用 HTTPS/mTLS、AD/LDAP/MFA、对象存储、数据库、消息队列、不可篡改审计、SIEM，以及独立安全域或网闸。
